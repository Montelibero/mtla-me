# Security policy

The deployed `v2` site and its current locked build dependencies are the supported production surface.

Report suspected vulnerabilities through the repository's [private vulnerability reporting](https://github.com/Montelibero/mtla-me/security/advisories/new) flow. Do not open a public issue containing exploit details, credentials, personal data, or information that could put site visitors at risk. If private reporting is unavailable, contact a repository administrator through an established private organizational channel and provide only the minimum information needed to arrange a secure handoff.

Reports should include the affected URL or file, reproduction conditions, security impact, and a safe proof of concept when available. Do not test against third-party services linked by the site without their authorization.
